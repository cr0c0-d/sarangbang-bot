# 사랑방봇 (sarangbang-bot)

음악 + 읽어주기 + 이미지 정리를 하는 개인용 디스코드 봇. 봇 하나로 세 가지를 합니다.

| 기능 | 하는 일 |
|---|---|
| 🎵 **음악** | 채팅방에 유튜브 링크를 붙여넣으면 음성채널에 들어가서 틀어줍니다 |
| 🗣️ **읽어주기(TTS)** | 지정한 채팅방에 글을 쓰면 음성채널에서 읽어줍니다 |
| 🖼️ **이미지 정리** | 올린 사진을 폴더별로 자동 저장하고, 웹페이지에서 여러 장을 골라 한 번에 받습니다 |

## 처음 한 번만 하는 설정

프로그래밍을 몰라도 됩니다. 순서대로 따라가면 됩니다.
**총 4단계, 20분쯤 걸립니다.**

### 1단계 — 디스코드에서 봇 계정 만들기

1. https://discord.com/developers/applications 접속 → 오른쪽 위 **New Application**
2. 이름 아무거나 입력 → **Create**
3. 왼쪽 메뉴 **General Information** → **APPLICATION ID** 를 복사해둡니다 → 이게 `CLIENT_ID`
4. 왼쪽 메뉴 **Bot** 으로 이동
5. **Reset Token** 클릭 → 확인 → 나온 긴 문자열을 복사해둡니다 → 이게 `DISCORD_TOKEN`
   > ⚠️ 이 토큰은 **비밀번호와 같습니다.** 남에게 보여주거나 인터넷에 올리지 마세요.
   > 창을 닫으면 다시 볼 수 없습니다. 잃어버리면 Reset Token을 다시 누르면 됩니다.
6. 같은 **Bot** 페이지를 아래로 스크롤 → **Privileged Gateway Intents** 항목에서
   **MESSAGE CONTENT INTENT** 를 **켭니다** → 아래 **Save Changes**

   > 🔴 **이걸 안 켜면 읽어주기와 링크 자동감지가 조용히 동작하지 않습니다.**
   > 에러도 안 나서 원인을 찾기 매우 어렵습니다. 반드시 켜세요.

### 2단계 — 봇을 내 서버에 초대하기

#### 2-1. 먼저 "서버에 설치"를 켜야 합니다 ⚠️

최근에 만든 앱은 **서버 설치가 기본으로 꺼져 있습니다.** 이걸 안 켜고 초대 링크를 열면
`이 애플리케이션에 지원되지 않는 설치 유형` 이라는 오류가 납니다.

1. 왼쪽 메뉴 **Installation** (설치) 으로 이동
2. **Installation Contexts** 항목에서 **Guild Install** 을 **체크**합니다
   (User Install 은 켜져 있어도 무관합니다)
3. 아래 **Default Install Settings** → **Guild Install** 에서
   - **Scopes**: `bot` 과 `applications.commands` 를 **둘 다** 추가
   - **Permissions**: 아래 항목들을 체크
     `View Channels` `Send Messages` `Read Message History` `Add Reactions`
     `Attach Files` `Embed Links` `Connect` `Speak`
     **`Manage Messages`** ← 음악 링크 메시지를 자동으로 지우는 데 필요합니다
4. 맨 아래 **Save Changes**

#### 2-2. 초대하기

같은 **Installation** 페이지의 **Install Link** 를 **Discord Provided Link** 로 두면
바로 아래에 초대 링크가 나옵니다. **그 링크를 쓰는 게 가장 확실합니다.**

직접 만들고 싶으면 아래 주소의 `여기에_CLIENT_ID` 자리에 1단계에서 복사한 APPLICATION ID를 넣으세요.

```
https://discord.com/api/oauth2/authorize?client_id=여기에_CLIENT_ID&permissions=3271744&scope=bot%20applications.commands&integration_type=0
```

서버를 고르고 승인하면 끝입니다.
(`permissions=3271744` = 메시지 보내기·관리, 반응 달기, 파일 첨부, 음성채널 연결·말하기.
`integration_type=0` 은 "사용자가 아니라 서버에 설치" 라는 뜻입니다)

### 3단계 — 채널 ID 알아내기

1. 디스코드 앱에서 **설정(톱니바퀴) → 고급 → 개발자 모드** 를 켭니다
2. 이제 채널이나 서버를 **우클릭하면 "ID 복사"** 가 생깁니다
3. 아래 것들을 복사해둡니다
   - 서버(맨 왼쪽 서버 아이콘) 우클릭 → ID 복사 → `GUILD_ID`
   - 음악 링크를 올릴 채팅방 → `MUSIC_TEXT_CHANNEL_ID`
   - 음악을 틀 음성채널 → `MUSIC_VOICE_CHANNEL_ID`
   - 읽어줄 글을 쓸 채팅방 → `TTS_TEXT_CHANNEL_ID`
   - 사진을 올릴 채팅방 → `IMAGE_CHANNEL_ID`

   > 💡 **채널 ID를 지금 다 모으지 않아도 됩니다.** 봇을 켠 뒤 디스코드에서
   > `/채널설정` 명령으로 채널을 골라서 지정하는 게 훨씬 쉽습니다.
   > 이 단계는 건너뛰고 `GUILD_ID` 만 채워도 됩니다.
   > 자세한 설명은 `.env.example` 파일 안에 항목마다 적혀 있습니다.

### 4단계 — 설정 파일 만들고 실행

`.env.example` 파일을 복사해서 `.env` 라는 이름으로 만들고, 위에서 모은 값들을 채웁니다.

```bash
cp .env.example .env
```

그다음 순서대로 실행합니다.

```bash
npm install
```

```bash
npm run update-ytdlp
```

```bash
npm run deploy
```

```bash
npm start
```

`✅ 로그인 완료: 봇이름#0000` 이 뜨면 성공입니다.

## 잘 되는지 확인하는 순서

한 번에 다 해보지 말고 **순서대로** 확인하세요. 어디서 막혔는지 알 수 있습니다.

1. 디스코드에서 `/핑` → "🏓 살아있습니다" 가 오면 봇 연결 성공
2. `/도움말` → 기능 목록이 보이면 슬래시 명령어 등록 성공
3. `/채널설정` 으로 음악·읽어주기·이미지 채널을 지정 → `/채널확인` 으로 확인
4. 음성채널에 들어간 뒤 `/재생 아무 노래 제목` → 음악이 나오면 음악 기능 성공
5. 음악 채팅방에 유튜브 링크만 붙여넣기 → 자동 재생되면 링크 감지 성공
6. TTS 채팅방에 아무 글이나 쓰기 → 읽어주면 TTS 성공
7. 이미지 채팅방에 사진 올리기 → ✅ 반응이 붙으면 저장 성공
8. `/갤러리` → 나온 주소를 브라우저로 열기 → 사진이 보이면 전부 성공

## 쓰는 법

### 🔌 기능 켜고 끄기 — 서버에 안 들어가고

`/기능` 을 치면 버튼이 나옵니다. **서버에 SSH로 들어가 프로세스를 끌 필요가 없습니다.**

```
🟢 🎵 음악        — 켜짐
🟢 🗣️ 읽어주기    — 켜짐
🟢 ⏰ 타이머      — 켜짐
🟢 🖼️ 이미지 정리 — 켜짐

[🎵 음악] [🗣️ 읽어주기] [⏰ 타이머] [🖼️ 이미지 정리]
[전체 켜기] [전체 끄기]
```

**언제 쓰나** — 서버에 이미 다른 음악봇·TTS봇이 있으면 같은 링크·같은 채팅에 둘이
동시에 반응해 겹칩니다. 그때 겹치는 기능만 끄면 됩니다.
고치면서 켜고 끄기를 반복할 때도 편합니다.

- 설정은 **서버별로 저장**되고 봇을 재시작해도 유지됩니다.
- 기능을 끄면 그 기능의 **명령어와 버튼도 막힙니다** ("꺼져 있습니다" 안내가 나옵니다).
- **음악을 끄면 재생 중인 것도 멈춥니다.** 음악·읽어주기가 둘 다 꺼지면 음성채널에서 나갑니다.
- **이미지를 끄면 새 사진만 저장하지 않습니다.** 이미 모아둔 갤러리는 계속 볼 수 있습니다.
- `/기능` `/채널설정` `/핑` `/도움말` 은 **항상 동작합니다** — 다 꺼놓고 되살릴 수 있어야 하므로.

### ⚙️ 채널 지정 — 여기부터 하세요

어떤 채널을 무엇에 쓸지는 **디스코드 안에서 바로 정할 수 있습니다.** `.env` 를 열 필요 없습니다.

| 명령어 | 설명 |
|---|---|
| `/채널설정 종류:<...> 채널:<...>` | 음악 채팅방, 음악 음성채널, 읽어주기 채팅방, 읽어주기 음성채널, 이미지 채널을 지정 |
| `/채널확인` | 지금 무엇이 어디로 지정되어 있는지 한눈에 보기 |
| `/채널해제 종류:<...>` | 지정을 풀고 `.env` 값으로 되돌리기 |

> ⚠️ **명령어로 지정한 값이 `.env` 보다 우선합니다.**
> 그래서 `.env` 를 고쳤는데 안 바뀌는 것처럼 보일 수 있습니다.
> `/채널확인` 이 각 항목 옆에 `명령어로 지정` / `.env 기본값` 을 표시해주니 그걸로 판단하세요.

### 🎵 음악

**친구들에게 알려줄 건 두 가지뿐입니다.**

1. 채팅방에 **유튜브 링크를 붙여넣기** (여러 개를 한꺼번에 붙여도 됩니다)
2. 조작은 **제어판 버튼**으로 (`/대기열` 로 띄웁니다)

> 💡 링크를 붙여넣으면 **그 메시지는 자동으로 지워지고**, 제어판이 항상 채팅방
> **맨 아래**에 남습니다. 곡을 추가해도 제어판이 위로 밀려나지 않습니다.
> 제어판이 갱신될 때 **푸시 알림은 울리지 않습니다.**
>
> 링크 메시지가 안 지워지면 봇에게 **메시지 관리(Manage Messages)** 권한이 없는 것입니다.
> 서버 설정 → 역할 → 봇 역할에서 켜주세요. (권한이 없어도 재생은 정상 동작하고 ✅ 반응만 붙습니다)

### 버튼으로 조작하기 (추천)

`/대기열` 을 실행하면 이런 제어판이 나옵니다.

| 버튼 | 하는 일 |
|---|---|
| ⏮️ 이전 | 직전에 들었던 곡으로 |
| ⏸️ / ▶️ | 일시정지 / 다시 재생 |
| ⏭️ 다음 | 다음 곡으로 |
| 🔁 반복 | 현재 곡 반복 켜기·끄기 |
| ⏹️ 정지 | 멈추고 대기열 비우기 |
| ⬆️ 드롭다운 | 고른 곡을 **다음에 재생**하도록 올리기 |
| 🗑️ 드롭다운 | 고른 곡을 대기열에서 빼기 |
| 🔄 새로고침 | 화면 갱신 |

곡이 바뀌면 **이 메시지가 알아서 갱신됩니다.** 채팅방에 "재생 중" 메시지가 쌓이지 않습니다.

### 명령어로 조작하기

| 명령어 | 설명 |
|---|---|
| `/재생 <링크 또는 검색어>` | 재생. 재생목록 링크를 넣으면 전부 대기열에 들어갑니다 |
| `/대기열` | **제어판 열기 (버튼)** |
| `/다음` `/이전곡` | 다음 곡 / 이전 곡 |
| `/정지` | 정지 + 대기열 비우기 |
| `/일시정지` `/이어재생` | 일시정지 / 다시 재생 |
| `/반복` | 현재 곡 반복 켜기·끄기 |
| `/대기열제거 <번호>` | 대기열에서 한 곡 빼기 |
| `/순서이동 <번호> <새번호>` | 순번 바꾸기 (새번호 1이면 맨 앞) |
| `/대기열비우기` | 재생 중인 곡은 두고 대기열만 비우기 |
| `/나가기` | 음성채널에서 나가기 |

**여러 곡 한 번에 넣기** — 링크를 여러 개 붙여넣으면 **보낸 순서 그대로** 대기열 뒤에 붙습니다.
한 메시지에 여러 줄로 넣어도 되고, 메시지를 연달아 보내도 순서가 지켜집니다.

마지막 곡이 끝나고 5분간 조용하면 알아서 나갑니다. (`MUSIC_LEAVE_AFTER_SEC`)

### 🗣️ 읽어주기

지정한 채팅방에 글을 쓰면 음성채널에서 읽어줍니다.

> 💡 **음성채널 안의 채팅창을 골라도 됩니다.** (디스코드 음성채널에는 자체 채팅창이 있습니다)
> 그렇게 지정하면 **그 음성채널에서 그대로 읽어주므로**, 읽어주기 음성채널을 따로 지정할 필요가 없습니다.
> 가장 자연스러운 설정입니다.

- 맨 앞에 **`//`** 를 붙이면 읽지 않습니다. (예: `//이건 안 읽힘`)
- 링크는 "링크"라고만 읽고, 멘션은 사람 이름으로, `ㅋㅋㅋㅋㅋ`는 3개로 줄여 읽습니다.
- `/읽어주기 켜기:false` 로 끄기
- **`/내목소리`** — 내 글을 읽을 목소리를 고릅니다. **사람마다 다르게 쓸 수 있습니다.**
  비우고 실행하면 서버 기본값으로 돌아갑니다.
- `/목소리` — 서버 기본 목소리 (개인 설정이 없는 사람에게 적용)
- `/목소리목록` — 14종 전부 보기 + 지금 내 설정 확인
- **음악을 듣는 중에 글이 오면** 음악이 잠깐 멈추고 읽어준 뒤 이어서 재생됩니다.

**한국어 말고 다른 언어를 쓰면?** — 목소리에 따라 크게 갈립니다. 실제로 측정한 결과입니다.

**목소리는 14종입니다.** Edge TTS가 "한국어"로 분류하는 건 3종뿐이지만,
**다국어 목소리는 한국어도 자연스럽게 읽습니다** (12종 전부 실측 확인). 그래서 14종을 제공합니다.

| 입력 | 다국어 목소리 (기본값 포함 12종) | 선희·인준 (한국어 전용 2종) |
|---|---|---|
| 한국어 | 정상 | 정상 |
| 한국어 + 영어 섞임 | 정상 | 정상 |
| 영어 문장 | 자연스러운 영어 발음 | 한국어 발음으로 어색하게 읽음 |
| 일본어 | 정상 | 🔴 **아무 소리도 안 남** (에러도 없음) |
| 중국어 | 정상 | 한자를 한국식 음독으로 읽음 |

그래서 기본 목소리를 **현수(다국어)** 로 두었습니다.
한국어 전용 목소리를 고르면 위 제약을 경고로 알려줍니다.

### ⏰ 타이머 (읽어주기 기능의 곁가지)

시간이 되면 **음성채널에서 소리로** 알려주고, 채팅으로도 멘션해줍니다.

| 명령어 | 설명 |
|---|---|
| `/타이머 15분` | 15분 뒤 알림 |
| `/타이머 1시간 30분` | `90m`, `1h30m` 처럼 써도 됩니다 |
| `/타이머 라면` | 등록해둔 단어로 바로 |
| `/알람등록 라면 3분` | 단어 등록 |
| `/알람등록 라면 삭제` | 단어 삭제 |
| `/타이머목록` | 진행 중인 타이머 + ❌ 취소 버튼 |

**시간 칸을 클릭하면 자주 쓰는 시간과 등록한 단어가 목록으로 나옵니다.** 외울 필요 없습니다.

- 음성채널에 들어가 있으면 **거기서** 소리로 알려줍니다. 안 들어가 있으면 채팅으로만 알립니다.
- 알람은 알림이 울려야 의미가 있으므로 **멘션으로 알립니다.** (음악 제어판과 반대)
- **봇을 재시작해도 타이머는 살아남습니다.** 꺼져 있는 동안 시간이 지났으면
  다시 켤 때 "몇 분 늦게 알렸다"고 밝히며 알려줍니다.
- 최대 24시간까지 걸 수 있습니다.

### 🖼️ 이미지 정리

**아무 설정도 필요 없습니다.** 봇이 볼 수 있는 **모든 채널**의 사진을 자동으로 저장하고,
폴더 이름은 **채널 이름**을 그대로 씁니다. ✅ 가 붙으면 저장된 겁니다.

즉 `#여행사진` 채널에 올리면 `여행사진` 폴더에 쌓입니다.

> 봇이 볼 수 있는 채널만 저장됩니다. 특정 채널을 제외하고 싶으면
> 디스코드 권한에서 그 채널의 봇 "채널 보기"를 끄면 됩니다. (아래 "잠가두기" 참고)

**어느 폴더에 들어가나?** — 위에서부터 먼저 맞는 규칙을 씁니다.

1. **스레드**에 올리면 → **스레드 이름**
2. `/폴더 여행사진` 을 실행해둔 채널이면 → `여행사진`
3. 그 외 → **채널 이름** (기본값)

`/채널설정` 에서 "이미지 채널"을 지정하면 **그 채널들만** 저장하도록 좁힐 수 있습니다.
다시 전체로 되돌리려면 `/채널해제` 하세요.

> 서버를 여러 개 쓸 때: 다른 서버에 같은 이름의 채널이 있으면 **같은 폴더에 섞입니다.**
> `/폴더 <다른이름>` 으로 한쪽을 바꿔주면 분리됩니다.

> 참고: 디스코드에서 **채널 이름을 바꾸면 그때부터 새 폴더**에 쌓입니다.
> 이전 사진은 예전 이름의 폴더에 그대로 남아 있습니다 (사라지지 않습니다).
> 합치고 싶으면 갤러리에서 사진을 골라 **옮기기** 하면 됩니다.

> 💡 **사진이 올라온 채널에는 "🖼️ 갤러리 열기" 버튼이 채팅방 맨 아래에 항상 떠 있습니다.**
> 매번 `/갤러리` 를 칠 필요가 없습니다. 새 사진이 올라오면 버튼이 아래로 따라 내려오고,
> 알림은 울리지 않습니다.

**여러 장 한 번에 받기** — 이게 핵심 기능입니다.

1. **보려는 채널에서** `/갤러리` 를 실행하면 **그 채널 폴더**의 주소가 바로 나옵니다
   — 친구들은 링크만 열면 됩니다. **암호 없음**
2. 사진을 클릭해서 여러 장 고릅니다
   - **Shift + 클릭** 으로 범위를 한꺼번에 고를 수 있습니다
   - **전체 선택** 버튼도 있습니다
4. **⬇️ 선택한 사진 받기** 를 누르면 **한 장씩 전부** 저장됩니다 (ZIP으로 묶지 않습니다)
   > 크롬이 처음 한 번 "여러 파일을 다운로드하시겠습니까?" 를 묻습니다. **허용**을 누르세요.

갤러리에서 사진을 다른 폴더로 **옮기거나 삭제**할 수도 있습니다.
이 두 가지는 되돌릴 수 없으므로 **관리 암호(`WEB_TOKEN`)를 한 번 물어봅니다.**
보기·내려받기는 암호가 없으니 친구들은 신경 쓸 필요 없습니다.

**누가 무엇을 볼 수 있나**

| 주소 | 누가 | 내용 |
|---|---|---|
| `/f/<폴더>` | **누구나** (링크만 있으면) | 그 폴더의 사진 보기·내려받기 |
| `/` (루트) | 누구나 | 안내만. **폴더 이름이 보이지 않습니다** |
| `/folders` | **나만** (`WEB_TOKEN` 필요) | 전체 폴더 목록 |
| 삭제·이동 | **나만** (`WEB_TOKEN` 필요) | — |

폴더 안에는 **뒤로가기 버튼이 없습니다.** 친구가 다른 채널 폴더로 넘어갈 수 없게 일부러 뺐습니다.
전체 목록은 서버 주소 뒤에 `/folders` 를 붙여 들어가면 됩니다 (암호를 물어봅니다).

기타 명령어: `/폴더목록` `/폴더확인` `/폴더 <이름>`

## 갤러리를 친구들도 열 수 있게 하기

기본값은 "이 컴퓨터 안에서만" 입니다. 친구들이 링크를 열 수 있게 하려면 두 곳을 바꿔야 합니다.

**① `.env` 수정**

```ini
WEB_BIND=0.0.0.0
WEB_PUBLIC_URL=http://<서버IP>:3000
WEB_TOKEN=길고_아무규칙없는_문자열
```

`WEB_PUBLIC_URL` 을 안 바꾸면 `/갤러리` 가 `localhost` 주소를 알려줘서 친구들이 열 수 없습니다.
(봇 시작 로그가 이 실수를 잡아서 경고해줍니다)

**② 서버 방화벽 두 곳 열기** — Oracle Cloud는 두 겹입니다.

콘솔에서 VCN → Security List 에 수신 규칙 추가 (`0.0.0.0/0` / TCP / `3000`), 그리고 서버에서:

```bash
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 3000 -j ACCEPT && sudo netfilter-persistent save
```

자세한 건 [docs/ORACLE-CLOUD.md](docs/ORACLE-CLOUD.md) 8단계에 있습니다.

> ⚠️ **공개하면 감수해야 하는 것**
> 통신이 HTTPS가 아니라 **평문**이고, 열린 포트는 자동 스캐너에 곧 발견됩니다.
> 사진 **보기·내려받기는 링크만 알면 누구나** 가능해집니다 (그게 요청하신 동작입니다).
> 다만 **삭제·이동은 `WEB_TOKEN` 으로 막혀 있으니** 그 값은 반드시 길게 설정하세요.

## 여러 서버에서 쓰기

봇 하나를 서버 2~3개에서 같이 쓸 수 있습니다. 서버마다 설정이 따로 저장되고,
음악 대기열도 서버별로 독립적입니다 (A서버에서 음악 듣는 중에 B서버에서 따로 틀 수 있습니다).

**해야 할 것은 하나뿐입니다** — `.env` 의 `GUILD_ID` 에 서버 ID를 쉼표로 나열하세요.

```ini
GUILD_ID=123456789012345678,987654321098765432
```

그다음 `npm run deploy` 를 실행하면 각 서버에 명령어가 등록됩니다.
어느 서버에 성공/실패했는지 하나씩 알려줍니다.

> ⚠️ **서버를 추가할 때마다 `GUILD_ID` 에 추가하고 `npm run deploy` 를 다시 실행해야 합니다.**
> 안 하면 그 서버에서는 슬래시 명령어가 보이지 않습니다.
> (유튜브 링크 자동 감지나 읽어주기 같은 메시지 기반 기능은 그래도 동작합니다)

> 📁 **이미지 폴더는 서버끼리 공유합니다.** 두 서버에 똑같이 `#사진` 채널이 있으면
> 같은 폴더에 함께 쌓입니다(파일이 사라지진 않습니다). 나누고 싶으면 한쪽 채널에서
> `/폴더 B서버사진` 처럼 이름을 다르게 지정하면 영구히 분리됩니다.

## 나만 쓰게 잠가두기 (권장)

개인용 봇이면 두 가지를 잠가두는 게 좋습니다. **초대를 끝낸 뒤에** 하세요.

### 1) 남이 내 봇을 데려가지 못하게 — Public Bot 끄기

기본값은 켜져 있어서, **APPLICATION ID만 알면 아무나 자기 서버에 초대할 수 있습니다.**
끄면 나(앱 소유자)만 초대할 수 있습니다.

> 🔴 **순서를 반드시 지키세요.** `Public Bot` 은 **Install Link 가 `None` 일 때만** 끌 수 있습니다.
> 그런데 Install Link 를 `None` 으로 두면 초대 링크 자체가 사라집니다.
> 즉 **잠근 뒤에는 새 서버에 초대할 수 없습니다.**

1. **쓰려는 서버 전부에 먼저 초대합니다** (2단계) — 2~3개면 세 곳 다 초대해두세요
2. 초대한 서버들의 ID를 `.env` 의 `GUILD_ID` 에 쉼표로 나열하고 `npm run deploy` 실행
3. 개발자 포털 → **Installation** → **Install Link** 를 **None** → Save
4. 개발자 포털 → **Bot** → **Public Bot** 끄기 → Save

**이미 들어가 있는 서버에서는 봇이 그대로 정상 동작합니다.** 새 초대만 막힙니다.
나중에 서버를 더 추가하려면 3번을 되돌려(Discord Provided Link) 초대한 뒤 다시 잠그면 됩니다.

> `Requires OAuth2 Code Grant` 는 **켜지 마세요.** 켜면 일반 초대가 아예 안 됩니다.

### 2) 특정 채널에서만 동작하게 — 두 겹으로 막기

**(가) 디스코드 권한으로 막기** — 봇이 다른 채널을 아예 못 보게 합니다.

1. 서버 설정 → **역할** → 봇 이름의 역할에서 **채널 보기(View Channels)** 를 **끔**
2. 쓰려는 채널 2~3개로 가서 → 채널 설정 → **권한** → 봇 역할을 추가하고
   그 채널에서만 **채널 보기 / 메시지 보내기 / 메시지 기록 보기 / 반응 추가** 허용
3. 음악·읽어주기를 쓸 **음성채널**에도 봇 역할에 **연결 / 말하기** 허용

이러면 다른 채널의 대화는 봇에게 아예 전달되지 않습니다. 가장 확실한 방법입니다.
**비공개 채널에서도 잘 동작합니다** — 봇 역할만 그 채널에 추가해주면 됩니다.

**(나) 봇 설정으로 막기** — `/채널설정` 으로 기능별 채널을 못박습니다.

특히 **음악 채팅방을 꼭 지정하세요.** 지정하지 않으면 봇이 **볼 수 있는 모든 채널**에서
유튜브 링크를 감지해 재생을 시작합니다. 친구들과 쓰는 서버에서는 성가실 수 있습니다.

```
/채널설정 종류:음악 채팅방  채널:#원하는채널
```

`/채널확인` 으로 지금 무엇이 어디로 지정됐는지 확인할 수 있습니다.

> 💡 슬래시 명령어 자체를 특정 채널에서만 보이게 하려면
> 서버 설정 → **연동(Integrations)** → 봇 선택 → 명령어별로 채널·역할을 제한할 수 있습니다.

## 문제가 생겼을 때

| 증상 | 해결 |
|---|---|
| **음악이 갑자기 안 나옴** | `npm run update-ytdlp` 실행 후 재시작. 원인의 90%입니다 |
| `Sign in to confirm you're not a bot` | 아래 "유튜브가 막힐 때" 참고 |
| **읽어주기가 무반응 (에러도 없음)** | 1단계 6번 **MESSAGE CONTENT INTENT** 를 안 켰습니다 |
| **슬래시 명령어가 안 보임** | `npm run deploy` 실행. 그래도 안 되면 2단계 초대 링크로 재초대 |
| `이 애플리케이션에 지원되지 않는 설치 유형` | 2-1단계 **Guild Install** 을 안 켰습니다 |
| **Public Bot 을 끌 수 없음 (회색)** | Installation → Install Link 를 먼저 `None` 으로 바꿔야 합니다 |
| **특정 채널에서만 봇이 반응 안 함** | 그 채널 권한에 봇 역할의 "채널 보기"가 있는지 확인 |
| **엉뚱한 채널에서 유튜브 링크에 반응함** | 음악 채팅방을 지정하지 않았습니다. `/채널설정` 으로 지정하세요 |
| **새로 추가한 서버에 명령어가 안 보임** | `GUILD_ID` 에 그 서버 ID를 추가하고 `npm run deploy` |
| **음성채널을 읽어주기 채팅방으로 못 고름** | 고칠 수 있습니다 (이제 지원). `npm run deploy` 후 다시 시도 |
| `로그인 실패` | `.env` 의 `DISCORD_TOKEN` 이 틀렸습니다 |
| **봇이 음성채널에 못 들어감** | 그 음성채널에서 봇에게 "연결"·"말하기" 권한이 있는지 확인 |
| **사진이 저장 안 됨** | `/채널확인` 으로 이미지 채널이 맞는지, 봇이 그 채널을 볼 수 있는지 확인 |
| **갤러리가 안 열림** | 봇이 실행 중인지, `WEB_PUBLIC_URL` 의 주소·포트가 맞는지 확인 |
| **친구는 갤러리를 못 열음** | `WEB_BIND=0.0.0.0` 인지, 방화벽 **두 곳**을 다 열었는지 확인 |
| **갤러리 링크가 localhost 로 나옴** | `.env` 의 `WEB_PUBLIC_URL` 을 서버 IP로 바꾸고 재시작 |
| **삭제·이동에서 암호를 물어봄** | 정상입니다. `.env` 의 `WEB_TOKEN` 값을 넣으세요 |
| **제어판 버튼이 반응 없음** | 명령어를 새로 등록해야 합니다. `npm run deploy` 후 봇 재시작 |
| **다른 봇과 겹쳐서 같이 반응함** | `/기능` 에서 겹치는 기능을 끄세요 |
| **"기능이 꺼져 있습니다" 가 나옴** | `/기능` 에서 그 기능을 켜세요 |
| **링크 메시지가 안 지워짐** | 봇 역할에 **메시지 관리** 권한을 켜주세요 |
| **제어판이 위로 밀려남** | 위와 같은 원인입니다 (링크가 안 지워져서) |
| **`.env` 를 고쳤는데 안 바뀜** | `/채널설정` 으로 지정한 값이 우선합니다. `/채널확인` 으로 출처를 보고 `/채널해제` 하세요 |
| **일본어가 소리 없이 넘어감** | 한국어 전용 목소리입니다. `/목소리` 로 **현수(다국어)** 를 고르세요 |
| **명령어가 아직 영어(`/play`)로 보임** | `npm run deploy` 를 다시 실행하세요. 등록해야 새 이름이 반영됩니다 |

### 유튜브가 막힐 때

**클라우드 서버(Oracle, AWS, GCP 등)에서 돌리면 거의 반드시 겪습니다.** 집 PC에서는 거의 안 생깁니다.
유튜브가 데이터센터 IP를 봇으로 판단해 막기 때문입니다.

증상이 여러 얼굴로 나타납니다 — 아래는 **전부 같은 원인**입니다.

- `Sign in to confirm you're not a bot`
- `The page needs to be reloaded` (몇 번 재시도해도 계속될 때)
- `playability status: LOGIN_REQUIRED`

**확인 방법** — 서버에서 실행하면 원인이 바로 보입니다.

```bash
cd ~/sarangbang-bot && ./bin/yt-dlp --simulate -v "https://www.youtube.com/watch?v=wp43OdtAAkM" 2>&1 | grep -E "LOGIN_REQUIRED|Sign in|ERROR"
```

`LOGIN_REQUIRED` 가 보이면 IP 차단이 확정입니다.

**해결: 쿠키 넣기**

브라우저에서 유튜브 쿠키를 파일로 뽑아 `.env` 의 `YTDLP_COOKIES_FILE` 에 경로를 넣습니다.
(브라우저 확장 프로그램 "Get cookies.txt LOCALLY" 계열로 `cookies.txt` 를 저장하면 됩니다)

> 🔴 **본인 주계정을 쓰지 마세요.** 데이터센터 IP에서 쿠키를 쓰다가
> 유튜브가 계정을 제한하는 사례가 있습니다. **따로 만든 계정**을 쓰세요.
> 이 파일은 그 계정의 로그인 정보 그 자체입니다 — 공유·커밋 금지 (`.gitignore` 에 이미 있습니다).

> 쿠키는 시간이 지나면 만료됩니다. 다시 막히면 새로 뽑아서 교체하세요.

**대안** — 계정을 걸고 싶지 않다면

| 방법 | 장단점 |
|---|---|
| **PO Token 제공자 설치** (`bgutil-ytdlp-pot-provider` 플러그인) | 계정 위험 없음. 설정이 더 복잡하고 별도 서비스를 띄워야 함 |
| **음악만 집 PC에서 돌리기** | 가장 확실. 가정용 IP는 차단되지 않음. 대신 PC를 켜둬야 함 |
| **주거용 프록시** (`YTDLP_PROXY`) | 동작하지만 유료이고 느림 |

```
YTDLP_COOKIES_FILE=C:\sarangbang-bot\cookies.txt
```
