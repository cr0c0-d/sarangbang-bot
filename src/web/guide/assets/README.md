# 가이드 캡처 자리

친구에게 공개해도 되는 PNG 캡처를 이 폴더에 추가하세요. 웹페이지 `/guide/stream`에 자동 표시됩니다.
파일이 없거나 읽을 수 없으면 캡처 위치 안내가 남습니다. 실제 업로드 기능은 없습니다.

| 파일명 | 캡처할 화면 |
|---|---|
| 01-start.png | 유튜브 일부공개 설정과 공유 링크 |
| 02-register.png | 디스코드 /방송 링크·게임명 입력, 진행 시간 확인 |
| 03-mark.png | ✂️ 지금! 버튼과 👥 다 같이 하던 순간 |
| 04-record.png | 녹화방의 방송자·날짜·미리보기·타임라인·클립 추출 버튼 |
| 05-clip.png | 마킹 선택 목록과 시:분:초 구간 입력창 |
| 06-save.png | 클립 웹페이지의 재생기·받기 버튼 |

가로 1,200~1,600px 권장. 파일을 공개하기 전에 스트림 키, 토큰, 관리자 암호, 개인 정보,
외부 공유에 동의하지 않은 사람의 대화·얼굴·영상 주소를 가리세요. 이 폴더는 공개 정적 경로입니다.
캡처 추가 후 커밋·푸시(확인 후)하고 서버에서 pull하면 됩니다. 친구 기기에서 읽기 쉬운지 확인하세요.
